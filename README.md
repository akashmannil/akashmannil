# Akash Mannil

Full-stack developer in Ontario, Canada. Mostly TypeScript, on both sides of the wire: Angular or React in front, Node/Express or NestJS behind, MongoDB or MySQL underneath.

Most of my open-source time goes to [Checkmate](https://github.com/bluewave-labs/Checkmate), a self-hosted infrastructure monitoring tool with 10k+ stars.
